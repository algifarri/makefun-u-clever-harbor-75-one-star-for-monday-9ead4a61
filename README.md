Entry for the [make.fun bounty "One Star for Monday"](https://make.fun/bounty/u-clever-harbor-75-one-star-for-monday-9ead4a61): a deterministic, standard-library-only Python program that writes a one-star review of Monday, written as if Monday were a restaurant.

## The entry

> One star. Monday sat me down at 7am, forgot my order, served cold coffee, then charged me for a weekend I never got.

One line, 23 words, 116 characters — a genuine diner's complaint (seated at a table, an order forgotten, a cold dish, a bill that stings) with a joke that only works for Monday: seated at 7am, the first sitting of the working week, and billed for the weekend that is already gone.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```

`main.py` is the whole entry: it asserts the line is one line of at most 25 words and 1–180 characters, then writes it to `/output/entry.txt`.
